## How the folders work

`papers/` and `strategy/` are relative links into `african-ai-policy/`. Edit through either location. Paper subfolders contain the writing; data and analysis shortcuts point back to their existing locations. Original `african-ai-policy/drafts/` paths remain compatibility links for existing scripts and references. Run analysis commands from their original repository directory.

No manuscripts, datasets, code, credentials, Git history or environments were edited or deleted. Earlier versions remain available; `archive` means a previous version or explicitly superseded assessment, not a discarded file. Filenames such as FINAL do not establish that a submission occurred.

The [move manifest](organization/moves-2026-10-18.json) records original and organized paths and SHA-256 hashes. [Verification](organization/verification.md) records the organization checks.
